# Roadmap

## 0.1 — Foundation

- Runnable dashboard and API
- Synthetic equipment and workflow records
- Shared contracts, tests, CI, security scanning, and contributor documentation

## 0.2 — Clinic operations

- Equipment assignment and return
- Cleaning, inspection, maintenance, and calibration history
- Role and permission foundation
- Accessible filtering, bulk actions, and exports

## 0.3 — Interoperability

- Stable OpenAPI contract
- Device adapter SDK and validation suite
- Versioned CSV/JSON exports
- Documented FHIR-aligned experimental mappings

## 0.4 — Operational readiness

- SQLite and PostgreSQL persistence adapters
- Audit reporting, backups, metrics, and structured logs
- Signed release artifacts and migration tooling

## 1.0 readiness criteria

- Published threat model and accessibility review
- Stable data contracts and migration policy
- Independent security assessment
- Community review with rehabilitation and clinical-operations practitioners

No roadmap milestone constitutes regulatory approval or certification.
